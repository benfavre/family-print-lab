A tiny Bambu Studio vendor folder (`vendor/BBL.json` + `vendor/BBL/`) for the profile tests. It is
written for these tests in the shape of Bambu Studio's `resources/profiles/BBL` at the tag in
`slicer/upstream.lock` (machine models, `inherits` chains, `include` of a G-code template and of a
filament template, `instantiation: "false"` bases, `filament_id` inheritance, "nil" vector slots, a
`compatible_printers_condition`, and a printer variant the model does not list, which must be dropped).
Preset names follow Bambu's; the values are made up.
