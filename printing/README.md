## Project workflow

1. Create `projects/<short-name>/` and copy the project template to its `README.md`.
2. Record the purpose, measurements, fit requirements, and model source or license.
3. Keep editable CAD, model exports, and slicer project files together in that folder.
4. Confirm the exact printer and nozzle before selecting a compatible slicer profile.
5. Record material, profile changes, print duration, and the result for each useful iteration.
6. Note the successful revision and any maintenance or follow-up work.

Printer-specific dimensions, compatibility, and settings remain unset until the model is confirmed.
