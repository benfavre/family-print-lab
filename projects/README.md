# Projects

No active projects yet.

Create a folder named for the project and copy [the template](../templates/project.md) into it as `README.md`. Use projects for printed parts for the office or home lab.

Add a link below when starting a project.

Suggested layout within each project:

```text
README.md       Purpose, measurements, settings, and results
cad/            Editable design sources
models/         Exported model files
slicer/         Slicer project files, such as 3MF
photos/         Fit references and print results
```

Create only the subfolders you need. Use revision names such as `cable-guide-v01` and record which model revision each slicer project uses.
