# Home-lab print ideas

These are candidates, not active projects.

| Idea | Measurements needed | Success check |
| --- | --- | --- |
| Cable labels | Cable diameters and label text / space | Labels are legible and stay attached |
| Cable comb | Cable count, diameters, and spacing | Cables route without pinching |
| Adapter storage tray | Adapter sizes and shelf space | Each adapter is accessible |
| Device feet or spacers | Device footprint and clearance | Device sits stably and vents remain clear |
| Small-device bracket | Device dimensions, weight, mounting points, vents | Bracket supports the device and preserves airflow |

For a chosen idea, create a folder under `projects/` using the [template](../templates/project.md). Record fit, load, and heat constraints where relevant before selecting material and geometry.
