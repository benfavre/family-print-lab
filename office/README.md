# Office print ideas

These are candidates, not active projects.

| Idea | Measurements needed | Success check |
| --- | --- | --- |
| Desk cable guide | Cable diameters, desk edge thickness, mounting space | Cables fit and stay accessible |
| Drawer divider | Internal drawer dimensions and item sizes | Divider fits and drawer closes freely |
| Small-parts tray | Available space and contents | Items are easy to sort and retrieve |
| Headphone hook | Headband width, mounting geometry, clearance | Hook fits and holds the intended load |

For a chosen idea, create a folder under `projects/` using the [template](../templates/project.md). Add measurements and photos before designing.
